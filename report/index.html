Re-optimize parameters

Markets drift, so the strategy's parameters go stale. This re-derives them from the latest data: download → optimize (last 12mo) → walk-forward check → propose. Nothing goes live until you review and click Apply.

CLI equivalent: .venv/bin/python3 backtest/reoptimize.py

Monthly auto-schedule

A monthly job runs the same pipeline automatically (1st of each month, 06:00). It only proposes — you still review and Apply here.

Install the schedule (macOS/Linux): .venv/bin/python3 backtest/reoptimize.py --install-cron

On Windows, use Task Scheduler to run the same command monthly.

Risk controls (built-in)

  • Position sized to risk a fixed % of balance per trade (drop to ≤ 0.5% before real money).
  • Skip entries when spread exceeds the cap.
  • Pause 24h after N consecutive losses; halt the day after the daily-loss cap.
  • Break-even then ATR trailing stop — same code path as the backtest.
